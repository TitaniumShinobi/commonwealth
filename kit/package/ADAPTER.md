# Simulation adapter v1

The installed adapter exposes reserve(reservation, endpoints, generation, expiry), attempt(reservation, generation, tick, confirmed, seed), and idempotent release(reservation). A reservation owns two distinct simulated endpoint IDs. Each modeled endpoint owns a separate allocation store. The virtual scheduler evaluates pending confirmation at each tick until the declared deadline. A modeled herald requires both confirmations before expiry. Missing confirmation stays pending until the deadline, then yields a timeout. Observe each endpoint's allocation before release, after release, and after idempotent release replay. Release reports both endpoint allocation counts. Record scope Simulation, model simulation-v1, template, seed, scheduler, and terminal state. A simulated outcome supplies no physical evidence.
