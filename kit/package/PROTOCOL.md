# Reference wire profile v1

Use TLS 1.3 with a fixture CA and mutually authenticated end certificates on 127.0.0.1. Pin the discovery connection to the locally approved serving-certificate SHA-256. Send one UTF-8 newline-terminated JSON object per request, up to 16 KiB. The service's `discover` response carries the operator-signed publication delegation and Ed25519 publication signature over the stable operator and service IDs, protocol 1, endpoint, serving DER certificate digest, revision and expiry. Signed bytes are sorted compact JSON with a trailing newline. Verify both signatures and the exact service scope before opening the protected connection. Match its certificate to the signed digest before writing the request.

Protected JSON fields are operation=request, protocol=1, service, action and request_id. The destination checks the TLS client identity against its local fixture grant or accepted peer card, then evaluates the action. Allowed fixture.read returns commonwealth-reference-v1. Fixture.write yields denied, no result, and mutated=false. Record the request ID on both sides. Health and discovery carry no protected record. This fixed fixture has one binding revision and no update or long-lived deployment policy.
