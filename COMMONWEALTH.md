## Commands

- Simulate — Run the declared topology with a versioned configuration and fixed seed.
- Conform — Run protocol, admission, isolation, revocation, and audit fixtures.
- Inspect — Show node state, active policy, link type, and event receipts.
- Recover — Restore a versioned configuration and exercise reconnect behavior.

## Core

- Objective — Free, open-source, decentralized quantum internet.
- Operators — Independent laboratories, communities, and participating institutions.
- Federation — Independently operated nodes cooperate through shared protocols and retain administrative control.
- Early user — WRECK, for provenance and consent applications.

## Rubric

- Simulation receipt — Record topology, configuration version, seed, inputs, and outputs.

## Security

- Household boundary — Protect digital systems with deny-by-default access, identity verification, appropriate device attestation, and explicit authorization.
- Network isolation — Separate participant traffic from management access and protect participants from lateral access.
- Application isolation — Run websites, applications, and search in separate execution domains with controlled interfaces.
- Revocation — Recheck permissions and enforce withdrawal across reconnects and restarts.

## Federation and Capability Coordination

- Discovery — Operators advertise supported services and protocol capabilities.
- Admission — Apply versioned rules to signed grants, requested scope, and current trust and revocation state.
- Receipt — Record the decision, reason, policy version, and evidence reference.
- Runtime — Operate independently of HYDRO, MDBO, AUTO, Chatty CLI, and AI models.

## Distributed Trust

- Identity — Keep trust roots under operator control and verify peer claims at federation boundaries.
- Integrity — Sign operator events and publish verifiable audit checkpoints.
- Shared state — Use decentralized agreement where independent operators must jointly maintain a record.

## Classical Connectivity

- Backhaul — Support authorized Internet connectivity over Starlink, fiber, or terrestrial radio.
- Transport boundary — Preserve federation, identity, access policy, and application interfaces across uplink changes.
- Pilot — Deliver free-to-user Internet access at one approved site over an authorized uplink.
- Recovery — Preserve ordinary Internet access during quantum adapter interruption.

## Quantum Networking

- Physical link — Use specialized hardware to establish and use shared entanglement between independently operated endpoints.
- Open interfaces — Publish control software, protocol specifications, simulations, and conformance tests.
- Telemetry — Tie measurements to identified instruments, documented conditions, and reproducible evaluation.
- Interoperability — Enable laboratories to operate their own implementations and extend them through shared interfaces.

## Free Access and Open Source

- Access model — Free to users, with no mandatory Commonwealth subscription.
- Software — Publish source, protocols, reproducible build instructions, and compatible implementation guidance.
- Operating costs — Cover equipment, power, connectivity, installation, and maintenance through project funding, hosts, sponsors, or participating institutions.
