Run the branch workflow. It runs inherited smoke and the Steps 3–9 and 11 regressions before the wired guest proof. The fixture uses a disposable guest namespace, a separate Linux gateway namespace, and the runner's ordinary upstream. The guest has only loopback and a single veth, with one DHCP-installed default route. No ingress port is exposed. Only the admitted guest's IPv4 HTTPS is forwarded. The edge forwards DNS for the fixture and records DHCP and resolver receipts. Egress requires a publicly trusted HTTPS response from example.com using curl with proxies disabled.

The wired operator path renders a target-bound nftables script in closed mode first and checks it with nftables before applying it inside the gateway namespace. The independently bootstrapped Ed25519 operator key signs the exact target digest and session intent. The test changes the target and MAC separately and expects denial. Withdrawal removes the allowed forwarding path in both directions and deletes matching connection state. The interface-loss exercise takes the gateway upstream down and restores it. The workflow verifies the archived receipts.

This is a staged runner fixture. The authenticated operator proof establishes a software binding for one wired guest. It is not wireless association, device identity attestation, or a substitute for separately qualified AP session enforcement. The existing isolated Step 7 regression provides distinct guest/L2, household and management control evidence. The separate mTLS peer is another test process.

For a real site, collect owner and activation authority, a specified audience, an authorized upstream agreement, accountable operator and recovery owner, equipment and firmware inventory, available Ethernet handoff and power/PoE, local management and recoverable baseline, and $0 participant terms backed by funded equipment, upstream, support, maintenance and continuity. Qualify the actual AP/controller and gateway's credential-to-session mapping, local bridge isolation, both directions of withdrawal after failed eviction, roaming/readdress/restart, and real DHCP/DNS/HTTPS on ordinary devices with alternate paths disabled. Approve numeric limits and a field window separately. The fixture cannot establish those prerequisites or authorize activation.
